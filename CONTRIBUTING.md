# Contributing to NewsLLM

## Development Workflow

1. Clone the repository.
2. Create a separate feature branch.
3. Keep changes focused and small.
4. Follow the existing project structure.
5. Review changes before committing.
6. Submit a pull request.

## Code Quality

Contributors should follow the existing Dart and Flutter conventions.

Recommended checks:

- flutter pub get
- flutter analyze
- flutter test

## Testing

New functionality should include appropriate unit or widget tests.

Existing tests should be preserved.

## Security

- Never commit API keys or private credentials.
- Do not expose Firebase service-account credentials.
- Avoid unnecessary Firebase security rule changes.

## Pull Requests

Pull requests should include:

- A clear description.
- The reason for the changes.
- Relevant testing information.
- Known limitations.
